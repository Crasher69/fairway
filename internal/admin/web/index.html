Getting started

  1. Add proxies. The Proxies tab: one at a time or as a list from your provider's price sheet.
  2. Group them into a list. The Lists tab: a list is a set of proxies within which Fairway picks the best one itself.
  3. Bind domains to the list. The Domains tab: a rule for an exact domain, for *.suffix, or a default list for everything.
  4. Send traffic. Set the HTTP proxy in your browser or application to —. As soon as requests flow, domains and measurements will appear here.

    Proxies

    Upstreams that carry the traffic. On their own they are not assigned anywhere: first they are grouped into a list, and the list is bound to a domain. File: config.json

    Add proxy

    A whole connection string — socks5://user:pass@1.2.3.4:1080 — can be pasted into “IP or host”, it will be split into fields.

    Import list

    One proxy per line. Understands 1.2.3.4:1080, 1.2.3.4:1080:login:password, login:password@1.2.3.4:1080 and full URLs with a scheme. Empty lines and lines starting with # are skipped.

    Lists

    A list is a set of proxies assigned to a domain. Within a list Fairway picks which proxy to use by itself and rebalances as measurements come in.

    Create list

    The name can be changed: references in domain rules and the default list are updated automatically.

    Domains

    A rule says which list serves a domain. Matching goes from specific to general: exact name → longest *.suffix → * → general settings.

    Add rule

    Zero in a limit means “take from general settings”, −1 means “unlimited”. Ban is a Go duration: 5m, 1h30m.

    General settings

    Apply to domains without a rule of their own and fill in wherever a rule has a zero.

    Without “allow direct” a domain with no rule gets a 503 — which is better than silently leaving from your real IP.

    Root certificate

    Download .crt

    Needed only for MITM mode: for the browser not to complain about a substituted site certificate, the machine must trust our root. It is created on first start and is unique to every installation — it is not built into the binary, otherwise the private key would be shared by everyone.

    Other machines on the network

    Download the .crt and import it into “Trusted Root Certification Authorities”. In a domain this is rolled out by group policy. Firefox, Java and Python keep their own stores — add it there separately.
