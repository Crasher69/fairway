    Прокси

    Апстримы, через которые уходит трафик. Сами по себе они никуда не назначаются — сначала собираются в лист, а лист уже привязывается к домену. Файл: config.json

    Добавить прокси

    Строку целиком — socks5://user:pass@1.2.3.4:1080 — можно вставить в поле «IP или хост», она разложится по полям.

    Листы

    Лист — набор прокси, который назначается домену. Внутри листа Fairway сам выбирает, через какой прокси идти, и перестраивает выбор по замерам.

    Добавить правило

    Ноль в лимитах означает «взять из общих настроек», −1 — «без ограничения».

    Общие настройки

    Без «разрешить напрямую» домен без правила получит 503 — и это правильнее, чем молча уйти с вашего реального IP.

    Корневой сертификат

    Скачать .crt

    Нужен только для режима MITM: чтобы браузер не ругался на подменённый сертификат сайта, машина должна доверять нашему корню. Он создаётся при первом запуске и у каждой установки свой — в бинарник не зашит, иначе приватный ключ был бы общим для всех.

    Установка на эту машину

    Ставится в хранилище текущего пользователя, права администратора не нужны.

    После установки машина будет доверять любому сертификату, подписанному этим ключом. Когда fairway больше не нужен — удалите сертификат этой же кнопкой.

    Остальные машины сети

    Скачайте .crt и импортируйте в «Доверенные корневые центры сертификации». В домене это раскатывается групповой политикой. Firefox, Java и Python держат своё хранилище — туда добавлять отдельно.
