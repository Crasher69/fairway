Как начать

  1. Добавьте прокси. Вкладка Прокси: по одному или списком из прайса поставщика.
  2. Соберите их в лист. Вкладка Листы: лист — это набор прокси, внутри которого Fairway выбирает лучший сам.
  3. Привяжите домены к листу. Вкладка Домены: правило на конкретный домен, на *.суффикс или лист по умолчанию для всех.
  4. Направьте трафик. В настройках браузера или программы укажите HTTP-прокси —. Как только пойдут запросы, здесь появятся домены и замеры.

    Прокси

    Апстримы, через которые уходит трафик. Сами по себе они никуда не назначаются: сначала собираются в лист, а лист уже привязывается к домену. Файл: config.json

    Добавить прокси

    Строку целиком — socks5://user:pass@1.2.3.4:1080 — можно вставить в поле «IP или хост», она разложится по полям.

    Импорт списком

    По одной строке на прокси. Понимает форматы 1.2.3.4:1080, 1.2.3.4:1080:логин:пароль, логин:пароль@1.2.3.4:1080 и строку со схемой целиком. Пустые строки и строки, начинающиеся с #, пропускаются.

    Листы

    Лист — набор прокси, который назначается домену. Внутри листа Fairway сам выбирает, через какой прокси идти, и перестраивает выбор по замерам.

    Домены

    Правило говорит, каким листом обслуживать домен. Подбор идёт от частного к общему: точное имя → самый длинный *.суффикс → * → общие настройки.

    ПаттернЛистTLS Прокси разом Соединений Бан

    Добавить правило

    Ноль в лимитах означает «взять из общих настроек», −1 — «без ограничения». Бан — как в Go: 5m, 1h30m.

    Общие настройки

    Действуют для доменов без своего правила и подставляются в правила там, где стоит ноль.

    Без «разрешить напрямую» домен без правила получит 503 — и это правильнее, чем молча уйти с вашего реального IP.

    Корневой сертификат

    Скачать .crt

    Установка на эту машину

    Ставится в хранилище текущего пользователя, права администратора не нужны.

    После установки машина будет доверять любому сертификату, подписанному этим ключом. Когда fairway больше не нужен — удалите сертификат этой же кнопкой.

    Остальные машины сети

    Скачайте .crt и импортируйте в «Доверенные корневые центры сертификации». В домене это раскатывается групповой политикой. Firefox, Java и Python держат своё хранилище — туда добавлять отдельно.
